1. Sobre a plataforma

A I·ten é uma plataforma digital de prospecção comercial B2B voltada ao mercado de refrigeração no estado da Bahia. A plataforma disponibiliza base de dados de empresas organizadas por município e segmento econômico (CNAE), com ferramentas de gestão de carteira e pipeline de prospecção.

2. Acesso e conta de usuário

O acesso à plataforma é individual e intransferível. Cada usuário é responsável pela confidencialidade de suas credenciais de acesso. É vedado:

  • Tentar acessar dados de outros vendedores ou áreas restritas

3. Uso dos dados da base

Os dados disponibilizados na plataforma (CNPJ, razão social, telefone, e-mail e segmento das empresas) são de uso exclusivo para fins comerciais de prospecção no contexto da equipe que utiliza a I·ten. É proibido:

  • Exportar, copiar ou reproduzir a base de dados para uso externo
  • Comercializar ou distribuir os dados para terceiros
  • Usar os dados para fins distintos da prospecção comercial autorizada

4. Carteira e exclusividade de prospecção
